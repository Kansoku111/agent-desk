# 既知の制約

[← README に戻る](../README.md)

- **応答は段階的に表示されません:** ACP 経由ではメッセージが確定した単位で届くため、文字ごとのストリーミング表示はありません。作業中は経過時間とツールの実行状況が表示されます。
- **dsh は developer preview です:** 互換性を壊す変更が頻繁に入るため、`@deepseek-ai/dsh` は特定の版に固定しています。版を上げるときは「設定 → 情報」の更新機能を使ってください。動作を確認し、問題があれば元に戻します。
- **サンドボックスは完全な隔離ではありません:** dsh の安全上の注意にあるとおり、Windows の読み取り専用モードは一部の経路を防ぎきれません。重要なリポジトリはブランチやバックアップを用意して使ってください。
- **シェルで変更したファイルは一覧に出ません:** 「変更したファイル」カードは、編集ツールと書き込みツールの結果から集計しています。
- **文字化け:** 日本語環境の PowerShell で、サンドボックスのエラーメッセージが文字化けすることがあります。dsh 側の出力の問題です。
- **利用規約:** ChatGPT サブスクリプションでの利用は、OpenAI の利用規約に従ってください。
