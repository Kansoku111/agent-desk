# 既知の制約

[← README に戻る](../README.md)

- **応答は段階的に表示されません:** ACP 経由ではメッセージが確定した単位で届くため、文字ごとのストリーミング表示はありません。作業中は経過時間とツールの実行状況が表示されます。
- **dsh は developer preview です:** 互換性を壊す変更が頻繁に入るため、`@deepseek-ai/dsh` は特定の版に固定しています。版を上げるときは「設定 → 情報」の更新機能を使ってください。動作を確認し、問題があれば元に戻します。
- **サンドボックスは完全な隔離ではありません:** dsh の安全上の注意にあるとおり、Windows の読み取り専用モードは一部の経路を防ぎきれません。重要なリポジトリはブランチやバックアップを用意して使ってください。
- **シェルで変更したファイルは一覧に出ません:** 「変更したファイル」カードは、編集ツールと書き込みツールの結果から集計しています。
- **文字化け:** 日本語環境の PowerShell で、サンドボックスのエラーメッセージが文字化けすることがあります。dsh 側の出力の問題です。
- **チームの認証・課金:** Claude Code のリーダーと子は通常の認証を引き継ぎます。API・クラウドも本人の認証情報で使えますが、認証方式ごとの課金確認が必要です（一度確認した方式は、ほかのチームにも使われます）。CLI 起動・再開と子ターンで再検査し、認証方式が変われば再同意が必要です。不明な方式では別のリスク同意も必要で、ログアウト状態では実行できません。この確認は請求額の保証ではありません。確認するのは認証方式であり、同じ方式のまま課金先アカウントが変わる場合や、起動後に Claude Code 内でログインを切り替える場合は検出できないことがあります。認証・請求先を変更したらチーム設定で再確認してください。自動処理には dsh の Claude（API）を推奨しますが、Claude Code とは実行方式・履歴が異なり、自動移行やフォールバックはしません。並列実行・長いターンの従量課金に注意し、各社の Console で支出管理を設定してください。Agent Desk は米ドル建ての厳密な支出上限を強制しません。
- **Claude Code の認証更新:** チーム・AB の認証確認はモデルを呼びませんが、Claude Code 自身がその確認中にログインの更新を始める場合があります。短い確認コマンドの終了で更新が中断される[報告](https://github.com/anthropics/claude-code/issues/95822)があり、同時の重複確認を減らしても、ログイン切れを完全には防げません。切れた場合は Claude Code のターミナルで `/login` してください。
