# 機能の詳細

[← README に戻る](../README.md)

## できること

- **ChatGPT サブスクで GPT モデルを使う:** Agent Desk として公式 Sign in with ChatGPT に登録し、`https://api.openai.com/v1/responses` を使います。以前の接続からは「もう一度サインイン（公式）」が必要です。旧資格情報を新しい登録へ変換・流用しません。
- **Claude を API キーで使う:** Anthropic の API キーを登録すると Claude モデルを選べます。DeepSeek の API キーも任意で使えます。
- **チームの Claude（API）の子:** 自動で進むチーム作業には「Claude（API）」を推奨します。登録済みの Anthropic API キーで動く dsh のタスクで、Claude Code とは別の実行方式・会話履歴です。初期設定ではオフで、自動での有効化や Claude Code からの移行・フォールバックはしません。並列実行や長いターンでは従量課金が大きくなるため、各社の Console で支出管理を設定してください。Agent Desk は米ドル建ての厳密な支出上限を強制しません。クレジットは各社の最新のプラン条件に従います。
- **Codex 風の画面:** ワークスペースごとのタスク一覧、作業時間の折りたたみ、コマンドと差分の表示、変更ファイルの一覧、承認カードがあります。
- **My PC とプロジェクト:** サイドバーは Codex のように「My PC」とプロジェクト（フォルダ）ごとにタスクをまとめます。My PC はリポジトリを参照しないタスク用で、作業フォルダはデータフォルダ内の `my-pc` です。
- **プロジェクト:** 「プロジェクトを作成」で名前とソースフォルダーを登録します。dsh のセッションは1フォルダで動くため、ソースフォルダーは1つです。
- **セッションの一括削除:** サイドバーの「複数選択」（チェックのアイコン）を押し、クリックで個別選択・Shift+クリックで範囲選択できます。Ctrl/⌘+クリックでも選択を始められます。Project見出しのチェックで、そのProjectの現在の検索・アーカイブ条件に一致するセッションを全選択できます。「削除」で件数を確認して実行します。Project本体と作業フォルダは残りますが、履歴は元に戻せません。実行中のセッションは停止します。失敗した項目は選択を残して再試行できます。
- **使用量の表示:** 回答の下に、そのターンの入力・出力トークン数を表示します。Claude と DeepSeek（API キーの従量課金）では、概算料金（米ドル）とタスクの累計も表示します。Claude はモデル一覧の単価、DeepSeek は公式料金表と応答記録の時刻から計算します。dsh のセッション記録から集計するため、ターンの完了直後に表示されます。
- **累計の使用量:** サイドバー下部に Claude の今月の料金を表示し、「設定 → 使用量」で今日・今月・全期間の合計、過去30日のグラフ、モデル別の内訳を見られます。Claude の Admin API キーを登録すると、Anthropic が集計した実際の請求額も表示します。詳しくは[使用量の表示](usage.md)を見てください。
- **Codex の利用上限:** 「画像生成と利用上限（Codex）」の別接続後、公式 app-server の `account/rateLimits/read` と更新通知から週間・5時間の窓を表示します。SIWC のアプリ別予算とは混同しません。未接続ならサインイン案内と [ChatGPT Settings → Usage](https://chatgpt.com/settings/usage) を表示します。
- **Claude の利用上限（チーム）:** エージェントチームの右パネルに、Claude サブスクリプションの5時間・週間の残りとリセット時刻を表示します。チームの Claude（`claude -p`）が自分の出力に含める `rate_limit_event` を読むだけで、使用量を調べるための通信や追加のターンはありません。そのため値は、チームの Claude が最後に動いた時点のもので、「○分前に取得」と併記します。ブラウザや他のターミナルで使った分も、次にチームが動いたときにまとめて反映されます。
- **モデルピッカーの表示設定:** 「設定 → モデル」のチェックで、選択一覧に表示するモデルを切り替えられます。「提供終了の可能性」があるモデルは既定で非表示になり、チェックを入れると表示できます。明示的に表示・非表示を選んだ設定は保持します。非表示のモデルはホイール切り替えや新しいタスクの自動選択からも除外され、再チェックで戻せます。設定は再起動後も残り、既存タスクのモデルやサブエージェントの設定は変わりません。
- **コンテキストサイズ:** 「設定 → モデル」で ChatGPT と Claude それぞれのサイズ（64K〜1M、500K を含む）を選べます。「モデルの既定サイズ」では、ChatGPT は公式 SIWC のモデル一覧が返す既定値に追従します（現在 GPT-6.1 Sol は 500K、GPT-5.5 は 272K）。既定値と最大値はモデルごとに取得・保存するため、再起動やオフライン起動でも使えます。各モデルが対応する最大値まで広げることもでき、GPT-6.1 Sol は最大 872K まで広げられます。手動で指定したサイズは保持され、対応する最大値を超えません。上限の 8 割で自動要約が走るため、小さくすると入力トークンと Claude の API 料金を抑えられます。小さくしたときは返答の枠も合わせて縮めます。
- **ブラウザ操作（Chrome）:** 設定 → 一般でオンにすると、エージェントが Chrome を操作できます（Google の chrome-devtools-mcp）。Chrome はエージェントが初めてブラウザツールを使ったときに、Agent Desk 専用のプロファイルで1つだけ起動し、全タスクで共有します。デバッグ用ポートは 127.0.0.1 だけで待ち受けます。ツール定義が毎回のリクエストに加わるため、不要ならオフにするとトークンを節約できます。
- **デスクトップ操作（Windows）:** 設定 → 一般でオンにすると、エージェントが画面のスクリーンショットを撮り、マウスとキーボードで PC 上のアプリを操作できます（既定はオフ）。Windows の標準機能（user32 と System.Drawing）だけで動き、追加のソフトや料金は要りません。スクリーンショットは 1280×800 に収まるよう縮小して送り、拡大ツールで細かい文字も読めます。権限モードに関係なく承認なしで実際の画面を操作するので、使うときだけオンにしてください。画像を読めるモデル（GPT・Claude）で使えます。
- **別のモデルのサブエージェント:** 通常のサブエージェント（`subagent`）はタスクと同じモデルで動きます。「設定 → モデル → サブエージェント」で Claude と ChatGPT それぞれのモデルを選ぶと、そのモデルで動く `subagent_claude` / `subagent_gpt` ツールが加わります。エージェントは、自分と同じ系統のツールを優先して使うよう案内されます（たとえば GPT-6 Astra のタスクは `subagent_gpt` で、設定した GPT に任せます。素の `subagent` と `subagent_fork` は常にタスク自身のモデルで動き、`subagent_fork` は子に会話を見せる必要があるときだけ使います）。GPT のタスクから Claude に、Claude のタスクから GPT に作業を任せることもできます（「Claude のサブエージェントで調べて」のように頼みます）。この案内はモデルへの指示で、守られる保証はありません。Claude の子は API の従量課金で、その料金は親のターンの使用量に合算して表示します。既定はどちらも「使わない」です。
- **workflow ツールはオフ:** dsh の `workflow` ツール（スクリプトで多数のサブエージェントを一度に起動する）は、Agent Desk では使いません。1回の呼び出しで多数の子が動き、メッセージやパーソナライズで決めたサブエージェントの回数制限をすり抜けるためです。毎回のリクエストからツール定義と説明文の約 4,000 文字も減ります。サブエージェントへの依頼は `subagent` などで行えます。
- **サブエージェントのパネル:** タスクがサブエージェントを使うと、画面右側に一覧が出ます。各サブエージェントのモデル名、推論レベル、状態（実行中・完了・エラー）、経過時間、今していることが、作業中も約 1 秒ごとに更新されます。カードをクリックすると、そのサブエージェントへの依頼内容、思考、ツールの実行、回答、親から受け取ったメッセージを時系列で表示します。会話中のサブエージェントの行にあるモデル名のボタンからも開けます。ヘッダーのボタンでパネルを開閉できます。ACP は子セッションの動きを送ってこないため、dsh がディスクに書く子セッションの記録（`server/subagents.js`）を読み取っています。表示はモデルの 1 応答ごとに進み、文字単位では流れません。
- **画像生成:** 既定オンの generate_image は、同梱 @openai/codex 0.164.0 の公式 app-server を使います。「画像生成と利用上限（Codex）」への別サインインが必要です。Agent Desk 専用 CODEX_HOME、空の作業ディレクトリ、read-only sandbox、最小限のツール設定で画像ターンを直列実行し、5分の未使用後にプロセスを終了します。画像は従来どおり generated-images に保存し、プレビューを表示します。参照画像は localImage 入力です。size/quality/background/format はプロンプトで指定するため厳密には保証されず、PNG が返った場合は JPEG/WebP に変換せず PNG として保存して通知します。設定OFFはツール呼び出し時にも確認します。
- **Web 検索:** 公式 SIWC の公開 Responses API と hosted web_search を使用します。アカウントの公開モデル一覧から検索用モデルを選び、出典付きの要約を返します。Claude のタスクからも利用でき、検索自体に Claude API 料金はかかりません。SIWC のプラン使用許可が必要で、別課金/旧接続へ自動切替はしません。
- **回答のファイルを開く:** 回答に出てきたファイルパス（`src/app.ts` のような表記やリンク）、画像、「変更したファイル」の一覧は、実在するものに下線が付きます。クリックで「開く・エクスプローラーで表示・パスをコピー」のメニュー、Ctrl+クリック（Mac は ⌘+クリック）で既定のアプリで開きます。`src/a.ts:42` のような行番号付きの表記も、そのファイルを指します。回答の中の画像（`![](generated-images/cat.png)`）はそのまま表示します。`generated-images/cat.png` や `C:\Users\me\shot.png` のようにパスだけ書かれた画像も、実在すれば回答の下に表示します（コードブロック内のパスと Web の URL は除きます）。実行ファイルやスクリプト（.exe、.bat、.ps1 など）は直接開かず、場所を表示します。
- **高速モード:** Claude の対応モデルに限り、設定や入力欄からオン・オフできます。GPT の高速モードは利用不可として表示します。
  - Claude: Opus 5.5・Opus 5・Opus 4.8 で、出力が最大 2.5 倍速くなります（Claude API の研究プレビュー、`speed: "fast"`）。料金は通常の 2 倍で、使用量の概算もオンだった期間の分を 2 倍で計算します。切り替えた直後はプロンプトキャッシュが効きません。
  - ChatGPT: 公式 SIWC 経路では高速モードを利用できません。priority が反映されないことを実測しているため、GPT のスイッチは無効で、過去のON設定もOFFへ移行します。
  - dsh はこれらの指定を pi-ai に渡さないため、Agent Desk が dsh の起動時にモジュールフック（`server/fast-mode-hook.js`）を読み込み、送信直前のリクエストに加えます。
- **パーソナライズ（カスタム指示）:** 「設定 → パーソナライズ」に書いた指示を、エージェントはすべてのタスクで作業の前に読みます（口調、回答の言語、毎回守ってほしいルールなど。最大 1 万文字）。Agent Desk が dsh の起動時にプラグイン（`server/instructions-plugin.js`）を読み込み、システムプロンプトの最後に加えます。サブエージェントにも渡ります。保存すると、作業中のタスクがなくなったときに dsh を再起動し、既存のタスクも次のメッセージから新しい指示を使います。会話の中での依頼と食い違うときは、会話の依頼を優先します。
- **推論レベル:** モデルが対応する範囲で、低・中・高・最高（xhigh）・最大（max）から選べます。対応しないレベルは、一番近いレベルで送ります。
- **権限モード:** 読み取り専用、ワークスペース、フルアクセスの3段階をタスクごとに選べます。
- **変更を戻す:** ファイルを変更した回答の下に「このリクエストの前に戻す」が出ます。押すと、戻るファイルと消えるファイルの一覧を確認してから、ワークスペースをその時点の状態に戻せます。戻したあとも「取り消す」で元に戻せます。詳しくは[変更を戻す](restore.md)を見てください。
- **Claude Code のタスク（CL）:** サイドバーのプロジェクト（または My PC）の「＋」の左にある「CL」を押すと、この PC に入っている Claude Code（`claude` コマンド）がそのフォルダで起動し、アプリの中のターミナルで使えます。dsh を通さない本物の Claude Code なので、料金や認証は Claude Code 自身のもの（サブスクリプションなど）で、Agent Desk に登録した API キーは使いません。
  - サイドバーでは「CL」の印が付き、作業中・承認待ち・待機中が表示されます。タスク名は Claude Code が付ける名前に変わります（名前を変更すると、そのまま固定します）。終わったときと承認を待っているときは、通常のタスクと同じように通知します。状態は Claude Code のフック（`--settings` で渡す `server/claude-hook.js`）から受け取ります。
  - ウィンドウを閉じても、Agent Desk が動いている間は Claude Code も動き続けます。開き直すと、今の画面から続きを表示します。Agent Desk の再起動などで止まったタスクは、開くと `claude --resume` で同じ会話を再開します。Claude Code を終了した場合は「会話を再開」を押します。
  - Claude Code が作業中の間、Agent Desk は終了も新しいコードへの入れ替えもしません（待機中のときは入れ替わることがあり、そのタスクは次に開いたときに再開します）。
  - ターミナルの下のボタン（「Sonnet 5.5 ｜ 高」のような表示）で、`/model` を打たずにモデルと推論の深さを切り替えられます。押すと左にモデル、右に推論の深さが出て、両方を選ぶと閉じて反映します（片方だけ変えるときは外側を押して閉じます）。ボタンのモデル名や推論の深さの上でマウスホイールを回すと、その片方だけが切り替わります。モデルは、モデル一覧にある Claude のモデルから選べます（一覧にない系統は、Claude Code の別名で「Opus（最新）」のように出ます。別名は新しいモデルが出ると自動でそちらに変わります）。Claude Code は起動時の `--model`・`--effort` でしか受け取らないため、待機中なら同じ会話を `--resume` で引き継いで起動し直します。作業中は変更できません。この指定はそのタスクだけのもので、Claude Code の既定の設定（`~/.claude/settings.json`）は変えません。新しい CL タスクは、最後に選んだモデルと推論の深さで始まります。
  - PC では普通のターミナルと同じように入力できます。Shift+Enter で改行、選択中の Ctrl+C でコピー、画像の貼り付け（またはドロップ）でその画像のパスを Claude Code に渡します。
  - スマホでは、画面の下に Esc・Tab・Shift+Tab・矢印・Enter・Ctrl+C のキーと、日本語入力や音声入力が使える入力欄が出ます。上下のスワイプでスクロールし、入力欄の左の 📎 で写真やファイルを選ぶと、そのパスを Claude Code に渡します（画像は Claude Code の入力欄に `[Image #1]` のように入ります）。
  - ターミナルの大きさは、最後に入力した画面（PC かスマホ）に合わせます。別の画面のサイズで表示しているときは「この画面に合わせる」で切り替えられます。サイズが変わると、Windows で表示が崩れないよう Claude Code に画面を描き直させます（Ctrl+L）。
  - タスクを削除しても、Claude Code 自身が保存した会話の記録（`~/.claude`）は残ります。
- **エージェントチーム（TM）:** 「CL」の左の「TM」を押すと、リーダー（Claude Code か GPT）と話すチームが始まります。リーダーが作業を分けて GPT・Claude・DeepSeek の子エージェントに任せ、終わった子から順に届く報告を確認します。Claude Code のリーダーと子は、本人の API キー・クラウドも含む通常の認証を引き継ぎます。開始画面・チーム設定でモデルを呼ばない認証状態の確認と、認証方式ごとの課金確認を行います（同じ方式なら、ほかのチームでは聞き直しません）。各 CLI 起動・再開と子ターンで再確認し、認証方式の変更には再同意、不明な方式には別のリスク同意も必要で、ログアウト状態では実行できません。保存済みの選択・モデル・履歴と通常の CL の動作は変えません。詳しくは[エージェントチーム](team.md)を見てください。
- **スマホから使う:** 「設定 → スマホ」でオンにすると、同じ Tailscale ネットワークにつないだスマホのブラウザから、タスクの確認、メッセージの送信、承認ができます。QR コードを読み取るだけでつながります。詳しくは[スマホから使う](remote.md)を見てください。
- **操作:** 途中停止、作業中の追加メッセージの予約送信、画像の添付、エクスプローラー・ターミナルで開く機能があります。
  - 予約したメッセージの「割り込む」を押すと、作業の終わりを待たずに今すぐ送ります。エージェントは作業を止めずに、次のステップでそのメッセージを読んで方針を変えます。送ったメッセージはそのターンの中に「作業中に送信」として表示します。ターンが終わりかけていて受け付けられないときは、予約のまま残して作業後に送ります。
  - 既存タスクへのメッセージは、サーバーの受領確認までブラウザの送信待ちに保存します。同じタブの再読み込み・再接続では同じメッセージ ID で受領を確認し、受領済みなら二重実行しません。「受領確認待ち」から進まないときは「受領を確認」を押してください。サーバーが割り込みを受け付けたか確定できない場合は「送信結果不明」として保留し、自動再送しません。会話を確認してから一覧から外してください（一覧から外す操作は、既に届いた依頼を取り消しません）。ブラウザの保存領域を消した場合やタブを閉じた場合の未送信メッセージは復元できません。
  - dsh はこの割り込み（steer）を ACP で受け付けないため、Agent Desk が dsh の起動時にモジュールフック（`server/steer-hook.js`）を読み込み、dsh-acp に受け口を加えます。dsh の更新でフックが合わなくなった場合は、「割り込む」を押しても予約のまま残ります（`npm test` の `steer-patch.test.js` が失敗して知らせます）。
- **公式SIWCのストリーム:** store=false/stream=true で必要な履歴を毎回送信し、response.completed を確認して成功とします。failed/incomplete/切断と使用上限エラーは区別し、勝手に別課金経路へ切り替えません。未対応パラメーターは送信直前に取り除き、モデルが受け付けない none 等の推論レベルを送らないよう対応レベルへ写像します。
- **通信失敗とプラン上限:** 一時的なネットワーク・5xx・途中切断は最大8回まで再試行します。認証/HTTP 4xxとsubscription-sharing使用枠エラーは再試行しません。同じ要求が2回続けて失敗したときは、3回目から過去の暗号化推論だけを省いて再送するガードを維持します。プラン上限ではタスク内に日本語の案内と [ChatGPT Usage](https://chatgpt.com/settings/usage) へのリンクを表示し、Agent Deskの上限やクレジット利用を見直せます。
- **画像生成の後片付け:** 画像turnはephemeral threadで実行し、画像データ取得後にCodex側のthread別generated_imagesを削除します。診断SQLiteとログもプロセス固有の一時フォルダへ分離して停止時に消すため、画像ごとの会話・画像・診断ファイルをCodexホームへ蓄積しません（認証と固定モデルcacheは保持）。
- **ゴールの自動継続:** エージェントがゴール（`create_goal`）を作ると、dsh はターンが終わるたびに次のラウンド（`<goal_round>`）を自動で始めます。dsh は最初のターンが終わった時点で返答を返すため、そのままではタスクが「完了」と表示されたまま裏で作業が続きます。Agent Desk は dsh の起動時にモジュールフック（`server/goal-hook.js`）を読み込み、ゴールが続く間はタスクを作業中のままにします。停止ボタンでラウンドを止めると、ゴールの自動継続も止まります。dsh の更新でフックが合わなくなると元の動きに戻ります（`npm test` の `goal-patch.test.js` が失敗して知らせます）。
- **更新の確認:** 起動時と6時間ごとに、dsh・同梱の Codex・Claude Code の新しい版を確認します。見つかるとサイドバーの「設定」に印が付き、「設定 → 情報 → 更新」にまとめて出ます。dsh と Codex は「指示をコピー」で AI エージェントへの更新の指示をコピーし、Claude Code は「更新」で `claude update` を実行します。詳しくは[dsh と Codex の更新](updating.md)を見てください。

## 権限モードについて

- **読み取り専用:** 書き込みはサンドボックスで拒否され、必要なときはエージェントが承認を求めます。
- **ワークスペース:** ワークスペース内の編集とコマンドは自動で実行し、範囲外は承認を求めます。
- **フルアクセス:** 制限も承認もありません。

dsh はセッションに権限モードを記録します。そのため既存のタスクでモードを変えると、新しいセッションに切り替わります。それまでの会話の要点は、次のメッセージに自動で添えて引き継ぎます。
