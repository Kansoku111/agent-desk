# スマホから使う

[← README に戻る](../README.md)

PC で動いている Agent Desk を、スマホのブラウザから使えます。通信は Tailscale（端末どうしを暗号化してつなぐ VPN。個人利用は無料）の中だけで行い、家の Wi-Fi やインターネットには公開しません。

1. PC とスマホに [Tailscale](https://tailscale.com/download) を入れて、同じアカウントでログインします。
2. PC の Agent Desk で「設定 → スマホ」を開き、「スマホから使う」をオンにします。「接続の確認」に Windows のファイアウォールの警告が出たら、「ファイアウォールで許可する」を押して、管理者の確認で「はい」を選びます。
3. 表示された QR コードをスマホのカメラで読み取ります。ブラウザの「ホーム画面に追加」で、アプリのように開けるようになります。

- **できること:** タスクの一覧と会話の表示、新しいタスクの開始、メッセージの送信（画像の添付も可）、承認、停止、モデルや権限モードの変更、各種設定。タスク右上の「開く → ビルドして再起動」も使えます（確認後、PC 側の実行中のタスクを停止して再起動します）。
- **PC で行うこと:** フォルダーの選択ダイアログ（スマホではパスを入力してプロジェクトを作れます）、ターミナル・既定のアプリで開く操作、ChatGPT のサインイン、スマホからの接続の設定。回答に出てきたファイルは、スマホではパスのコピーと画像の表示ができます。
- **PC が動いている必要があります:** オンの間は、ウィンドウを閉じても Agent Desk がバックグラウンドで動き続けます。止めるときは「スマホから使う」をオフにしてからウィンドウを閉じてください。PC がスリープすると、スマホからはつながりません。
- **リンクの管理:** リンク（QR コード）には、起動をまたいで変わらない専用のトークンが入っています。リンクを知っていれば PC でエージェントを操作できるので、他人に教えないでください。「新しいリンクを作る」を押すと古いリンクは使えなくなり、接続中のスマホも切断されます。トークンはデータフォルダの `remote.json` に保存されます。
- **つながらないとき:** 「接続の確認」に原因が出ます。スマホが Tailscale につながっていない（この PC しか表示されない、オフライン）ときは、スマホの Tailscale アプリで同じアカウントにログインし、接続をオンにします。Windows は Node.js への許可を最初に聞かれたときのネットワークの種類（パブリックなど）にしか付けないため、Tailscale（プライベート）からの接続が止められていることがあります。「ファイアウォールで許可する」は、Tailscale のアドレス（100.64.0.0/10）からこのポートへの TCP 接続だけを許可するルール `AgentDesk-Remote-Tailscale` を追加します。
- **待ち受けるアドレス:** Tailscale の CLI が答えればそのアドレス、答えなければ名前に「Tailscale」を含むネットワークのアドレス（100.64.0.0/10）だけです。ポートは既定で 47131 です（`--remote-port` か環境変数 `AGENT_DESK_REMOTE_PORT` で変更できます）。Tailscale が後から起動しても、15 秒ほどで待ち受けを始めます。
- **通知:** スマホのブラウザでは、Tailscale の通信は暗号化されていても `http://` のページになるため、ブラウザの通知は使えません。画面を開いている間は、完了や承認待ちを画面内に表示します。
