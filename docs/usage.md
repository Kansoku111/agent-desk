# 使用量の表示

[← README に戻る](../README.md)

「設定 → 使用量」には、出どころの違う2つの数字を並べます。

- **Agent Desk での使用量（概算）:**
  - すべてのタスクの応答を dsh のセッション記録（`dsh-home/sessions`）から集計し、Claude と DeepSeek の API 料金を見積もります。追加の設定は要りません。
  - Claude はモデル一覧の単価を使います。DeepSeek は [公式料金表](https://api-docs.deepseek.com/quick_start/pricing/)の入力・キャッシュ・出力単価を使い、応答記録の時刻でピーク／オフピークを判定します。単価の確認日と対応モデル、中国の祝日日程は `server/deepseek-pricing.json` に記録します。未登録年の祝日は割引を推定せず、平日のピーク時間には高い方の単価を使います。
  - DeepSeek の過去の回答も、トークン数が保存され、対応するセッション記録が残っていれば開いたときに料金を補完します。料金改定前の記録も保存済みの単価で見積もるため、実際の請求額と異なる場合があります。正確な請求額は各社の管理画面で確認してください。
  - 削除したタスクの分も含みます。集計結果はログごとに `usage-history.json` に保存し、変わったログだけを読み直します。
  - 日付はパソコンの時刻（ローカル時刻）で区切ります。
  - ChatGPT のサブスクリプションは定額なので、トークン数だけを表示します。
- **Claude の請求額（実額）:**
  - Anthropic の Usage & Cost API から取得します。Claude Console の「Cost」と同じ数字で、Agent Desk 以外での利用も含みます。
  - この API は Admin API キー（`sk-ant-admin…`）か、ワークスペースを限定しない個人キー・サービスアカウントキーでしか読めません。登録済みの Claude の API キーで読めなければ、画面から Admin API キーを登録します。
  - Admin API キーは組織の管理者だけが作成でき、個人アカウントでは使えません。キーは `dsh-home/.credentials.yaml` に保存されます（dsh はこのキーを使いません）。
  - 初回に過去1年分を取得して `claude-cost.json` に保存し、以後は直近の数日分だけを取り直します。日付は UTC 基準で、利用から反映まで数分かかります。
