# 変更を戻す

[← README に戻る](../README.md)

dshで動く通常タスクでは、リクエストを送るたびに、エージェントが作業を始める前と終えたあとのワークスペースを保存します。「このリクエストの前に戻す」を押すと、その時点の状態に戻します。

Codex（GP）とClaude Code（CL）はこのチェックポイント復元の対象外です。

- **戻るもの:** 変更されたファイルは元の内容に、削除されたファイルは復元、新しく作られたファイルは削除します。編集ツールだけでなく、コマンドで変更したファイルも対象です。そのリクエストより後のリクエストで行った変更も、まとめて戻ります。
- **会話:** 会話の履歴はそのまま残ります。次のメッセージに、ファイルを戻したことを自動で添えてエージェントに伝えます。
- **取り消し:** 戻したあと、新しいメッセージを送るまでは「取り消す」で戻す前の状態にできます。部分的に失敗した場合は再試行でき、取り消し先は最初に戻す前の状態を維持します。
- **戻らないもの:**
  - ワークスペースの外への変更、インストールしたソフト、送ったメール、ブラウザやデスクトップでの操作など、ファイル以外への影響
  - 保存対象外のファイル（未追跡で `.gitignore` に一致するもの、`node_modules` などの依存パッケージやキャッシュ、保存時または復元時に 50 MiB を超えるファイル）。いったん保存対象になったファイルは、後から `.gitignore` に追加しても自動では対象外になりません。
  - ワークスペースの中にある別の Git リポジトリやシンボリックリンク
- **注意:** 戻す範囲にある、あなた自身が手で編集した内容も戻ります（戻す前の確認画面に一覧が出ます）。ほかのアプリで開いているファイルは戻せないことがあります。保存に失敗した場合は、その不完全な保存を復元・取り消しの基準にしません。
- **以前の保存:** 対象外ファイルや保存失敗を記録していない古いチェックポイントは、安全に復元・差分レビューできないため使用しません。必要な場合は別のバックアップや Git 履歴を利用してください。
- **保存先:** データフォルダの `checkpoints`（ワークスペースごとの Git リポジトリ）です。ワークスペース自身の Git には何も書き込みません。Git が必要です。タスクを削除すると、そのタスクの保存分も消えます。
- **大きなフォルダ:** 保存に 45 秒以上かかるフォルダでは、7日間この機能を休止し、タスクにその旨を表示します。
- 「設定 → 一般 → 変更を戻せるようにする」でオフにできます。
